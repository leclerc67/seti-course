# Учебник «Сети для будущего SOC-аналитика»

Локальное приложение. Одна страница без сборки и зависимостей.

**Обновлено:** 11.08.2026

---

## Как запустить

Ярлык **«Сети — учебник»** на рабочем столе. Открывается в полноэкранном окне без браузерной
обвязки. Интернет не нужен.

Публичная копия: <https://leclerc67.github.io/seti-course/>

---

## Из чего состоит

| Файл | Назначение |
|---|---|
| `index.html` | весь учебник: разметка, стили, скрипты, схемы — единым файлом |
| `server.js` | локальный сервер на Node: отдаёт страницу и хранит прогресс |
| `progress.json` | **прогресс пользователя** — не удалять |
| `manifest.json` | описание приложения для установки в систему |
| `icon-192.png`, `icon-512.png` | значки, сгенерированы скриптом `../_shared/make-icons.js` |
| `start.vbs` | запуск: поднимает сервер и открывает окно приложения |

Порт **7801**. Сервер слушает только `127.0.0.1` и сам выключается через 5 минут после закрытия окна.

## Как править

Правится **только `index.html`**. Сборки нет, шаблонов нет — открыл, поменял, сохранил, обновил окно.

Внутри файла порядок такой: `<style>` с токенами оформления → разметка всех экранов
→ `<script>` с логикой. Каждый модуль — отдельный `<section class="view" id="v-mN">`,
показывается по одному.

### Что нельзя ломать

- **`/*__PROGRESS__*/null`** в скрипте — сервер подставляет сюда сохранённый прогресс при отдаче
  страницы. Уберёшь — перестанет загружаться прогресс.
- **`data-fin="N"`** у чекбоксов завершения модуля — по ним считается прогресс.
- **`data-quiz`** и **`data-i`** у тестов, **`data-task`** у открытых заданий — это ключи хранения
  ответов. Поменяешь — ответы пользователя потеряются.
- Массив **`MODS`** в скрипте задаёт порядок модулей, названия карточек и время. Идентификатор `id`
  должен совпадать с `id` секции без префикса `v-`.

### Добавить термин в словарь

В массив `GLOSS`: `['Название', 'категория', ['основа1','основа2'], 'Определение']`.

- категория — один из ключей в `GCATS`;
- **основа пишется без окончания**: `маршрутизатор`, `инкапсуляц`, `уязвимост`. Окончания
  подставляет регулярное выражение `END`;
- проверь, что основа не поглощает посторонние слова: `порт` не должен ловить «портфель».
  Механизм требует, чтобы после основы шло допустимое окончание и затем не-буква.

Термины размечаются в тексте автоматически при открытии модуля. Первое вхождение подчёркивается
точками, последующие — нет, но подсказка работает на всех.

## Как хранится прогресс

Всё в `progress.json` рядом с приложением. Структура:

```json
{
  "done":  { "m0": true },              // пройденные модули
  "seen":  { "m0": true, "m1": true },  // открытые модули
  "quiz":  { "m0_1": "ok" },            // ответы на тесты: ok | no
  "task":  { "w1": 3 },                 // открытые задания: 3 полностью, 2 частично, 1 слабо
  "hit":   { "w1": { "0": true } },     // отмеченные пункты рубрик
  "note":  { "w1": "текст" },           // написанные пользователем разборы
  "drill": { "solved": 0, "streak": 0, "best": 0 },
  "pos":   { "m2": 1840 },              // позиция прокрутки по разделам
  "last":  "m2",                        // где закрыли — туда и вернёмся
  "ts":    1786423997881
}
```

Дублируется в хранилище браузера, но основной источник — файл.

## Грабли, на которые уже наступали

Читать обязательно перед правками — всё это уже стоило времени.

**Прогресс не сохранялся.** Внутри claude.ai страница считается сторонней и браузер стирает её
данные при закрытии. Решение — режим приложения с записью в файл. Хранилище браузера оставлено
как запасной путь, но полагаться на него нельзя.

**Кириллица в именах ярлыков.** Системная локаль для не-Unicode программ не русская, и COM-объект
Windows при сохранении `.lnk` превращает русские буквы в `?`. Обход: создать ярлык с латинским
именем и переименовать через `[System.IO.File]::Move` из PowerShell.

**Кодировка при открытии с диска.** Без `<meta charset="utf-8">` файл, открытый по `file://`,
показывает кракозябры. В сборке для приложения и сайта этот тег добавляется обёрткой — не потерять.

**Красная полоса заголовка.** Это системный цвет заголовка Windows, из страницы не убирается.
Решение — запуск сразу в полный экран (`--start-fullscreen` в `start.vbs`) плюс кнопка F11.

**Экранирование в командной строке.** Bash-heredoc и PowerShell портят обратные слэши и кириллицу.
Скрипты с регулярками писать **файлом**, а не через `node -e` или `-Command`.

**Не удалять `progress.json` при отладке.** Один раз он был принят за тестовый и стёрт вместе
с настоящим прогрессом. Перед удалением — посмотреть содержимое.
