# Сети для будущего SOC-аналитика

Два интерактивных курса под одну задачу — первая работа аналитиком мониторинга в центре
информационной безопасности. При открытии страница спрашивает, какой курс читать; выбор
запоминается, а вернуться к нему можно в любой момент без потери прогресса ни в одном из курсов.

**Читать:** https://leclerc67.github.io/seti-course/

## Курс 1 · Сети

От кадра Ethernet до строчки в SIEM. 11 модулей, готовы все.

| Модуль | Тема |
|---|---|
| 00 | Как работает SOC |
| 01 | Уровни и инкапсуляция, VLAN, ARP |
| 02 | IP, маски, NAT, DHCP, атака через Router Advertisement |
| 03 | Маршрутизация, TTL, ICMP |
| 04 | Порты и сокеты, firewall |
| 05 | TCP и UDP, сканирование, SYN-flood, QUIC |
| 06 | DNS: один запрос от начала до конца, кеш, злоупотребления |
| 07 | HTTP и HTTPS, TLS, C2 поверх легитимных сервисов |
| 08 | Wireshark, Suricata, Zeek, разбор дампа |
| 09 | Почта и фишинг, SPF/DKIM/DMARC |
| 10 | Разбор алертов, Sysmon, запросы к SIEM, фазы реагирования, экзамен |

| Модуль | Тема | Готов |

| 02 | PowerShell для чтения: командлеты, конвейер, журналирование, признаки атак | ✓ |
| 03 | Журнал событий: Event ID наизусть | — |
| 04 | Sysmon | — |
| 05 | Атаки в домене: pass-the-hash, kerberoasting, DCSync | — |
| 06 | Капстоун: разбор доменных алертов | — |

## Общее для обоих курсов

Словарь на 343 термина с ранжированным поиском, 14 схем, тёмная тема по умолчанию
(есть переключатель на светлую). В курсе «Сети» — 12 открытых заданий на разбор логов,
где ответ нужно сформулировать, а не выбрать из вариантов, тренажёр подсетей с бесконечной
генерацией задач и капстоун «Смена: очередь алертов».

## Устройство

Одна страница без зависимостей и сборки: весь HTML, CSS, скрипты и схемы обоих курсов
лежат в `index.html`. Открывается и с диска, и с любого хостинга статики.

Прогресс хранится в браузере отдельно для каждого курса. Кнопки на главной сохраняют его
файлом и загружают обратно — так он переносится между устройствами.
