# Сети для будущего SOC-аналитика

Два интерактивных курса под одну задачу — первая работа аналитиком мониторинга в центре
информационной безопасности. При открытии страница спрашивает, какой курс читать; выбор
запоминается, а вернуться к нему можно в любой момент кнопкой «Все курсы» внизу боковой
панели — она же показывает, сколько пройдено во втором курсе. Прогресс, ответы и заметки
у курсов раздельные и при переключении не теряются.

**Читать:** https://leclerc67.github.io/seti-course/

## Общее для обоих курсов

Словарь на 367 терминов с ранжированным поиском, 16 схем и 110 вопросов с разбором каждого
неверного варианта. Часть вопросов помечена «из прошлых модулей» — они спрашивают не тему
текущего модуля, а связку с уже пройденным: на смене алерты тоже не приходят по главам.
Тёмная тема по умолчанию, есть переключатель на светлую.

**Тренажёр команд** — в 14 модулях из 18, 38 шагов. Печатаешь команду, он разбирает ввод
и показывает, что вернула бы настоящая машина: Unix-команды в курсе по сетям, PowerShell,
конвейеры и чтение журналов в курсе по домену. Сверка нестрогая — регистр, порядок
параметров и лишние пробелы значения не имеют, а при ошибке он называет, чего не хватает.

**21 открытое задание на разбор** — 10 в курсе по сетям, 11 в доменном. Ответ нужно
сформулировать своими словами, а не выбрать из вариантов; после этого открывается рубрика,
по которой себя проверяешь. Плюс тренажёр подсетей с бесконечной генерацией задач.

**Два капстоуна.** В курсе по сетям — «Смена: очередь алертов»: шесть срабатываний надо
сначала расставить по приоритету, потом вынести вердикт. Наборов алертов **два** — ночная
смена и дневная, с разными сюжетами и своими итогами; второй нужен, чтобы пересдача через
месяц проверяла разбор, а не память о первой очереди. В доменном капстоуне — четыре разбора
вперемешку, где тема не подсказана, и цепочка событий с трёх машин, которую надо собрать
в правильном порядке. Оба просят прогноз до проверки и показывают расхождение с фактом.

## Устройство

Одна страница без зависимостей и сборки: весь HTML, CSS, скрипты и схемы обоих курсов
лежат в `index.html`. Открывается и с диска, и с любого хостинга статики.

Прогресс хранится в браузере отдельно для каждого курса. Кнопки на главной сохраняют его
файлом и загружают обратно — так он переносится между устройствами.
