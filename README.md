# Сети для будущего SOC-аналитика

Интерактивный учебник по компьютерным сетям, собранный под одну задачу — первая работа
аналитиком мониторинга в центре информационной безопасности.

**Читать:** https://leclerc67.github.io/seti-course/

## Что внутри

11 модулей, 9 схем, тренажёр подсетей с бесконечной генерацией задач и 10 открытых
заданий на разбор логов, где ответ нужно сформулировать, а не выбрать из вариантов.

| Модуль | Тема |
|---|---|
| 00 | Как работает SOC |
| 01 | Уровни и инкапсуляция, VLAN, ARP |
| 02 | IP, маски, NAT, DHCP, атака через Router Advertisement |
| 03 | Маршрутизация, TTL, ICMP |
| 04 | Порты и сокеты, firewall |
| 05 | TCP и UDP, сканирование, SYN-flood, QUIC |
| 06 | DNS и пять способов им злоупотребить |
| 07 | HTTP и HTTPS, TLS, C2 поверх легитимных сервисов |
| 08 | Wireshark, Suricata, Zeek, разбор дампа |
| 09 | Почта и фишинг, SPF/DKIM/DMARC |
| 10 | Разбор алертов, Sysmon, запросы к SIEM, экзамен |

## Устройство

Одна страница без зависимостей и сборки: весь HTML, CSS, скрипты и схемы лежат
в `index.html`. Открывается и с диска, и с любого хостинга статики.

Прогресс хранится в браузере. Кнопки на главной сохраняют его файлом и загружают
обратно — так он переносится между устройствами.
